# Wishlist App - Frontend

## 使用技術
- Next.js
- React
- TypeScript

## 起動方法

`frontend` ディレクトリで以下のコマンドを実行します。

### パッケージのインストール

```bash
npm install
```

### ローカル環境の立ち上げ

```bash
npm run dev
```

### ビルド・本番相当の起動

```bash
npm run build
npm start
```

## アクセス先
- Frontend：http://localhost:3001
- API：http://localhost:3000
